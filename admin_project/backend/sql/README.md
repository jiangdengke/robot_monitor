# SQL Bootstrap

文件：
- `init.sql`

用途：
- 一键创建 `robot_monitor` 数据库核心表
- 写入后台登录、菜单、角色、字典、参数等基础数据
- 写入少量机器人、区域、桌台、航班、旅客、点餐、AI 示例数据

默认账号：
- 用户名：`admin`
- 密码：`admin123`

定位：
- 这是“管理后台最小可用 bootstrap SQL”
- 不是从生产库完整导出的全量恢复脚本
- 重点是让 `backend/admin` 能尽快具备本地启动和页面联调的最小数据基础
- `sys_menu.component` 已尽量贴近当前前端构建产物里的真实 Vue 视图路径

已知限制：
- 某些复杂业务表字段是根据反编译 mapper 反推的最小集合
- 如果后续启动时报缺字段/缺表，需要继续增补
- 外部依赖（Redis、模型服务、Kafka、DeepGlint、机器人服务）仍需单独准备或在配置里降级/替换
- 这份 SQL 的目标是“先让后台能进、能看、能联调”，不是保证所有业务链路达到生产可用
